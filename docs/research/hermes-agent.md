# 研究笔记：Hermes Agent

- 项目：[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)（MIT；阅读时的 commit 为 `3294d683`，2026-09-30）
- 阅读时间：2026-09-30
- 结论：学思路，不搬代码。它是 Python 写的通用 AI 代理，强在消息入口、自我学习闭环和长任务执行；记忆很薄。PCAS 的差异化仍然是记忆核心。

## 它是什么

一个"自进化"的通用代理：可以在终端、桌面应用，以及 Telegram、Discord、WhatsApp、Signal 等消息平台上使用；能调用 40 多种工具（终端、浏览器、代码执行等）；会从经验中总结技能，支持定时任务和子代理委派，也能输出训练轨迹。

它的记忆很简单：两个有字数上限的 markdown 文件（`MEMORY.md` 约 2200 字符，`USER.md` 约 1400 字符），在会话开始时固定成快照注入系统提示；再加上 SQLite FTS5 的会话全文搜索。可选插件 Honcho 负责用户建模。

## 值得借鉴的做法

| 做法 | 它怎么做 | PCAS 怎么用 | 阶段 |
|---|---|---|---|
| **消息网关** | 一个网关进程接入多个 IM 平台，支持语音转写，跨平台保持对话连续；社区有微信桥接 HermesClaw | Telegram 不只用来收提醒，还能和秘书对话，在手机 App 之前充当手机入口 | 第 1 阶段 C2 |
| **提示词缓存友好** | 记忆在会话开始时固定成快照，会话中途不改系统提示，保证前缀缓存命中 | 秘书的系统指令固定不变，上下文按"越稳定越靠前"排列 | 第 1 阶段 B1 |
| **技能 = 流程记忆** | 复杂任务完成后，后台分叉一个代理回顾这一轮，决定要不要保存或更新技能；curator 定期把长期不用的技能标为过时、归档 | 记忆核心补上"做法"这一类：工作室做完一件事，沉淀"这类事怎么做"；同样需要过时和归档机制 | 第 3 阶段 |
| **`/goal` 加裁判** | 设定目标后，每轮结束由小模型判断完成、继续还是卡住；可以附完成条件和质量门槛（必须跑通的命令） | 副手在工作室里做长活时使用；完成条件写进任务，由小模型判断 | 第 3 阶段 |
| **Kanban 多代理协作** | 持久化的任务板，每张卡片由独立的 worker 处理；有迭代预算、接近上限时提醒、熔断 | 副手执行时的预算、检查点和失败熔断 | 第 3 阶段 |
| **按任务配辅助模型** | 压缩、视觉、会话搜索、curator 等辅助任务各有一个模型槽位，可以单独指定更便宜的模型 | 模型调度的第一版：按任务类型配模型，先不做智能路由 | 第 5 阶段 |
| **provider 回退与凭据池** | 按价格、延迟排序 provider，失败时回退，多个 key 轮换 | 模型调度的降级规则 | 第 5 阶段 |
| **定时任务的无代理模式** | 定时跑脚本，把输出原样投递，完全不调用模型；定时任务也可以由外部 webhook 事件触发 | "能用规则就不用模型"；事件驱动加时间驱动 | 第 5 阶段 |
| **Honcho 用户建模** | 每 N 轮对话后推导出关于用户的结论（偏好、习惯、目标），逐步累积 | 习惯层可以学它"定期推导、结论带证据"的节奏，但结论要进结构化层，可以纠正 | 第 7 阶段 |
| **轨迹压缩** | 把执行轨迹压缩到 token 预算内：保留开头和最后 N 轮，中间做摘要，用作工具调用模型的训练数据 | 数据熔炉的样本整理 | 第 6 阶段 |
| **撤销与重试** | `/undo`、`/retry` 在各个界面都能用 | 我们已经把撤销作为核心原则 | 已采纳 |

## 不借鉴的部分

- **记忆方式**：只有两个有字数上限的文本文件加全文搜索，适合编程助手，不适合"比你妈还了解你"。PCAS 坚持三层结构化记忆。
- **通用代理的工具面**：终端、浏览器、代码执行等 40 多种工具，以及 1 万多个文件的复杂度。PCAS 是个人秘书团队，重点在记忆、安排和可视化，不做通用编程代理。
- **以命令行和斜杠命令为主的交互**：PCAS 的原则是一句话办事、能可视化就可视化。

## 可能的集成方向

PCAS 的记忆可以通过 MCP 服务提供给外部代理，让 Hermes 这类擅长电脑操作、浏览器和写代码的代理当"外包副手"：PCAS 负责记忆、授权和调度，它负责执行，结果再回写到 PCAS。这符合 PRD"不同 AI 在授权范围内共享同一份记忆"的要求。可以在第 5 阶段（接入扩展和模型调度）评估。
