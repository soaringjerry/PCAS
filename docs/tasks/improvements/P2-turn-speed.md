# P2 记忆多了以后，秘书回一句话又变慢了

2026-10-05。执行者 6.1 Sol。分支 `fix/p2-turn-speed`，从 `origin/main` 建；工作区 `/root/PCAS-wt/p2`；Draft PR 的 base 是 `main`。

前情见 [P1](P1-recall-speed.md)：2.7 万条原话时秘书回一句话要 46 秒，当时只改了回忆那一条查询。

## 现象

线上记忆从 2500 条涨到 5254 条后，秘书回一句话从 8–10 秒变成 27–36 秒（2026-10-05 实测，三句话各测两轮）。和第 2.5 阶段第 1 批无关：后台整理不在跑的时候一样慢。

## 已经量到的

在一轮对话期间每 0.4 秒看一次数据库正在执行什么，共 55 次采样（约 27 秒）：

| 正在执行的查询 | 采样次数 | 在哪 |
|---|---|---|
| 没有查询在执行（等模型） | 10 | — |
| 读记忆列表（`SELECT r.id::text,c.version,c.nature,…`） | 10 | `memories_read.go` 的 `readMemoriesTx` |
| 回忆（`WITH linked AS …`） | 9 | `retrieval.go` 的 `recallTx` |
| 已采纳结果的权限检查（`WITH applicable AS MATERIALIZED …`） | 9 | `artifacts.go` 的 `sanitizeItemTx` |
| 读原对话窗口 | 4 | `evidence_context.go` |
| 快照里的已整理条数 | 4 | `workspace.go` 的 `snapshotTx` |
| 快照里的记忆总数 | 3 | 同上 |
| 其余 | 6 | |

也就是说一轮里模型只占约五分之一，其余都在数据库上。

单独量过的两个数（线上只读）：

- `SELECT version FROM applicable_claim_versions(owner, now(), now()) WHERE claim_id = X` 一次约 1.7 毫秒；不带条件取全部 5254 条约 1 秒。
- `sanitizeItemTx` 里那条语句对一个有已采纳结果的事项原来要 1.16 秒；把当前版本改成整条语句只算一次后是 0.16 秒，结果逐行相同（PR #193，已上线）。但一轮里它被调用很多次，总量仍然可观。

## 我对原因的判断（请验证，不要当成结论）

1. 「一条记忆现在以哪个版本为准」是按行调用函数算的。读记忆列表、统计条数时每条记忆调一次，条数翻倍，时间翻倍。函数内部还对每条记忆再调一次 `claim_source_is_current`。
2. 秘书每一轮都把这个用户的全部记忆读出来（`deskContextTx`），再从里面挑回忆命中的那二十条。记忆越多，这一步越慢，而它读出来的绝大部分没有用。
3. 回一句话的响应里带着整个工作台快照，快照里又统计了一遍记忆总数和已整理条数。
4. `sanitizeItemTx` 在一轮里对同一个事项被调用多次（列表里、历史回执里、生成前后的两次核对）。

## 要交付什么

目标：**秘书回一句话时花在数据库上的时间，不随记忆条数明显增长。** 具体验收数字：

- 在一个有 10,000 条记忆、30,000 条原话、20 个事项（其中 5 个有已采纳结果）的虚构库上，一轮秘书对话里数据库部分合计不超过 2 秒（模型用假的，立刻返回）。
- 同样的库在 2,500 条记忆时和 10,000 条时，这个数相差不超过 2 倍。
- 给一个可以重复跑的量法（测试或脚本），以后改动可以再量。

要求：

- **结果不能变。** 每一处改动前后，对同一份数据返回的内容逐字节相同。P1 的做法是在一个只读事务里新旧各跑一次比对，照这个来，并把比对写成测试。
- 可见范围、排除项、当前版本的规则一条都不能松。宁可少优化一处，不能改语义。
- 先量再改。每改一处，报告它在上面那个库上省了多少；没有明显效果的改动不要留。
- 可以加索引和迁移（编号找协调者要，下一个是 036）。如果要新增「当前版本」的物化数据，写清楚它在哪些写入路径上维护、怎么保证和函数算出来的一致，并加一条随机序列测试核对两者始终相同。
- 不改接口的返回形状。确实需要让回一句话的响应不再带完整快照，先停下来告诉协调者，这会牵动前端。

## 不要做的

- 不动第 2.5 阶段第 1 批的整理逻辑（`organize.go`）。快照里「已整理条数」那条查询可以改写法，结果不变。
- 不用线上数据。虚构库自己造。
- 不部署。

- 每一处改动：改了什么、省了多少、新旧结果相同的证据。
- 你验证过的原因里，哪些和上面「我的判断」不一样。
