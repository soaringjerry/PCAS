# PCAS Web 原型

用来明确真实使用需求的交互原型（[需求文档](../docs/prd.md) §8）。数据只保存在本机浏览器，
还没有接后端；页面只通过 `src/store` 里的 action 读写数据，接后端时替换这一层即可。

## 运行

需要 Node.js 22.12 或更新版本。

```bash
cd web
npm install
npm run dev
```

提交前运行：

```bash
npm run lint
npm run type-check
npm run build
```

## 页面

| 路径 | 内容 | 对应需求 |
|---|---|---|
| `/` | 今天：唤醒的想法、今天要做、等待中 | §5 |
| `/inbox` | 收件箱：采纳、修改、合并或忽略提取出的候选 | §5 捕捉轻便 |
| `/tasks` | 任务：状态、截止与安排时间、依赖、提醒与触发 | §3 TODO 与日程、§4 |
| `/ideas` | IDEA：演变、搁置原因、重新考虑的条件、唤醒 | §3 IDEA 追踪与唤醒 |
| `/projects` | 项目：进度、结论、下一步 | §5 事情独立于聊天 |
| `/memory` | 记忆：可信度、版本、来源、可见范围、删除影响 | §2、§6 |
| `/handoffs` | 交接：生成、预览、发出、结果回流 | §3 Prompt 与文档生成 |
| `/agents` | AI 接入：每个 AI 可读取的记忆范围 | §3 多 AI 接入、§6 |
| `/sources` | 来源与后台作业 | §3 跨应用数据规整、§5 过程可理解 |
| `/training` | 训练数据：候选、纳入、排除、导出 JSONL | §3 后训练数据导出 |

顶部输入框随时可以记一句话，按 `/` 聚焦。

## 走一遍典型场景（§7）

1. 在“今天”点“模拟导入成本测算”：导入一份成本资料，搁置的 IDEA「用本地小模型做记忆提取」
   因条件满足被唤醒，并说明原因。
2. 在唤醒卡片上点“转成任务”，再从任务详情里点“交给外部 AI”，生成交接内容。
3. 发出后把 AI 的回复贴回来，修改后采纳：结果写回项目进度，并成为一条训练候选。

左下角“重置示例数据”可以恢复初始状态。
