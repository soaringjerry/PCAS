# 第 3.6 阶段：秘书会收拾（入口与规则）

2026-10-08。上位依据：[白皮书](../../whitepaper.md) §3「一句话办事」「先做后报」、[界面与交互原则](../../design/principles.md)。协调者直接实现，没有分给执行窗口。

## 0 为什么有这一期

第 3.5 阶段把期限表整张接到了首页。上线当天用户指出：时间线上一堆乱七八糟的东西，删不掉，跟秘书说也删不掉；没有确定时间的事应该是待办，不该在时间线上。

查下来三处都偏离了「真秘书」这个定位：

| 该有的 | 3.5 上线时的样子 |
|---|---|
| 一句话，能办的马上办 | 秘书只有建待办、建想法、建项目、加步骤、改事项、派副手六个动作，碰不了记忆和期限 |
| 秘书自己有判断 | 期限表 148 行原样上首页：过去的行程、别人报的时效、只是考虑过的习惯，每天都在 |
| 不把活推给用户 | 第一反应是给每行加一个 × 和一张让用户勾的清单 |

规则写错的地方在契约：3.5 的 A1、A2 规定「期限表里有什么，首页就显示什么」。往屏幕上放东西的规则，以后先问一句：真秘书会不会把这个摆到你面前。

## 1 定下的事

1. **时间线只放有时间的。** 没钟点的固定安排、日期没说清的，不上首页时间线，留在资料库「眼下」。有日期的截止和预约、有钟点的固定安排、有时间的待办照旧。（3.5 的 A2 作废。）
2. **每一行都能了结，了结分三种**：做完了、不要了、已转成待办。都标在底下那条记忆的这一版上（`deadline_completed*` 三个键加 `deadline_closed_as`：`done` / `dropped` / `task`），记忆本身不动，了结后首页、「眼下」、给秘书看的那张表都不再列它；都进操作记录，能撤销。
3. **一句话就能了结。** 秘书多一个动作 `close_date`（引用那一行所附记忆的 `M*`）。用户说做完了、不要了、别再提、早就不这样了，直接办；说「这其实是件要办的事」，先建待办再了结为 `task`。
4. **后台自己收拾，先做后报。** 新阶段 `memory.date_tidy`：日期没说清的、没钟点的固定安排、过去超过一天的截止和预约，每条按记忆版本只判一次——留着、不再显示、建成待办、建成想法。建出来的事项带来源标记（`creation.by = background_tidy`，依据是那条记忆），回执在「你不在的时候」；不再显示的合成一行「收拾了日程：N 条…」，点开每条有理由和【放回去】。
5. **首页的 × 只是兜底**，不是主要的路。

## 2 规则

- **判断交给模型，程序只校验**：输出必须是 `keep / drop / task / idea` 之一并带理由；`task`、`idea` 的标题按事项标题的现有规则校验。看不懂的输出什么都不改，记为失败后重试。拿不准一律 `keep`（提示词里写明）。
- **不重复建**：模型能看到当前未完成的待办（最近 40 条）和想法（最近 20 条）的标题，已有同一件事就判 `drop`。这两个数和秘书每轮看到的一样（2.6 C6）。
- **一条只问一次**：判定存在 `date_tidy_checks`（记忆、版本、类别各一行）。`keep` 也存，所以不会反复问；用户撤销过的也不会再做一遍。记忆改了版本，或者有日期的那条过了期（类别变了），才重新判。
- **预算**：每小时 30 次调用，独立计数，不借别的阶段的。依据：一次调用只看一条，几百条的存量一天内清完，平时每天只有几条。超出的任务等下一个小时，不丢。
- **截断要记数**：原话和记忆各取前 1200 字，超出的字数记进观测台。
- **过去多久才判**：有日期的行过去满一天才进入判断，昨晚到期的截止还留在首页等用户自己打勾。
- **模型在判的时候用户先动了**（了结了、改了记忆）：这次判定作废，什么都不改。
- 2.6 的通用规则 G1–G7 照旧。

## 3 上线前在真实通道上看过的

在线上备份的副本上（不动线上数据）用默认通道跑完了全部存量，原始判定逐条看过，见[上线记录](../../evaluations/2026-10-08-phase3_6-rollout.md)。

## 4 顺带查出来的线上问题

3.5 上线后后台排班每一轮都让步（`schedule_background_write_busy` 每小时 65–74 次）：按主题读成员走的是全量视图，线上 35 个够条件的主题在两秒写窗口里读不完，整轮回滚，交接说明、估工作量、主题建项目都没在排。已单独修复（PR #288）。3.5 的验收夹具只有 3 个够条件的主题，没测出来——规模夹具要按线上的实际数量级造。

## 5 没做的

- 用一句话改某条日程的时间（「改到下周」）：日期是从记忆里读出来的，要改的是记忆，这一期没接。
- 把存量记忆整体过一遍提项目和想法：只做了有日期的这部分。
- 观测台里单独一页看「收拾了什么、为什么」：数据已经在 `date_tidy_checks` 里，页面没做，目前从首页那一行点开看。
