# PCAS Web 原型

用来明确真实使用需求的交互原型（[需求文档](../docs/prd.md) §8）。数据只保存在本机浏览器，
还没有接后端；页面只通过 `src/store` 里的 action 读写数据，接后端时替换这一层即可。

## 运行

需要 Node.js 22.12 或更新版本。

```bash
cd web
npm install
npm run dev
```

提交前运行：

```bash
npm run lint
npm run type-check
npm run build
```

## 结构

以“事情”为中心：项目、想法和待办都是事情，类型可以变（想法转成待办，待办聚成项目）。
导航只有三个入口，加上设置。

| 路径 | 内容 | 对应需求 |
|---|---|---|
| `/` | 现在：需要你拿主意的事（唤醒、到期、结果回来、出错）、等你确认的 AI 推测、正在推进 | §5 |
| `/things` | 事情：推进中 / 放着的 / 结束了 | §5 事情独立于聊天 |
| `/t/:id` | 一件事的文档页：状态、时间、条件、笔记，以及包含来源和交接的来龙去脉 | §3、§4 |
| `/handoff/:id` | 交接：要交代的、发出去、收回来 | §3 Prompt 与文档生成、多 AI 接入 |
| `/library` | 资料库：记忆（可信度、版本、可见范围、删除影响）、来源与后台作业、训练数据 | §2、§3、§6 |
| `/settings` | 自动化范围、各 AI 能看到的记忆、导出全部数据 | §5 主动但可控、§6 |

随时按 `⌘K` / `Ctrl K` 或 `/` 记一笔、查找或跳转；手机上用底部的加号。

视觉上是一本温暖的笔记本：纸色底和点阵、霞鹜文楷（本地自带字体，不连外部字体服务）做标题、
波浪下划线标出 AI 推测的内容，已确认的内容不加标记。

## 走一遍典型场景（§7）

1. 在“现在”点“导入成本测算”：放下的想法「用本地小模型做记忆提取」因条件满足被唤醒，并说明原因。
2. 点“转成待办”，在待办页右侧“交给 AI”写交接；把未确认的成本数据“没错，带上”。
3. 发出后把 AI 的回复贴回来，修改后采纳：结果写回原来的事情，并成为一条训练候选。

设置页底部“恢复”可以回到初始示例数据。
