2026-10-03 用户提出三个问题，协调者查代码后确认都是真的。这是一个中等大小的任务（要动模型通道、后台处理、Telegram、网页四处），交给一个执行者实现，协调者读代码、上线、线上验证。

## 现在是什么样（查代码确认）

1. **在 Telegram 里发图片**：机器人把图片存成一份资料，回一句「收到，已存进资料」。秘书看不到图片里有什么；只有配了文字说明时，秘书才按那句文字办事。（`internal/telegram/poller.go`）
2. **网页上**：跟秘书说话的输入框不能带图片和文件。要传文件只能去资料库点「导入资料」，那也只是存起来，不是说给秘书听。
3. **图片里的字**：后台用传统的文字识别程序 tesseract 读（`internal/postgres/attachments.go` 的 `ocrImage`）。它只认印刷体文字，认不出截图的版面、照片里的东西、手写、表格，也不知道这张图是什么。现在没有任何一个模型通道接收图片（Codex 通道还特意关掉了看图）。

## 要做成什么样

**R1 模型通道能看图。** 模型通道多一个能力：给一张图和一句要求，返回文字。按通道协议分别实现：OpenAI 兼容接口和 Responses 用图片输入；Anthropic 用图片块；ChatGPT 官方授权通道（`internal/ai/siwc`）用 Responses 的图片输入；Codex 通道如果它的应用服务器支持传图就接上，不支持就明确报「这个通道不能看图」。每次调用照常记一行花费，用途写 `vision`。

**R2 读图用模型，传统识别只当后备。** 后台处理图片（以及扫描版 PDF 的页面图）时，先用能看图的通道读：把图里的文字原样抄出来，再用一两句话说明这是什么图。结果存成这份资料的文字，表示方式标成 `vision`。没有能看图的通道、调用失败、或者超出每日预算时，退回现在的 tesseract，行为和现在一样，并在资料的处理状态里看得出用的是哪一种。用哪个通道看图：默认用默认通道；默认通道不能看图时用第一个能看图的；设置里不加新的开关。

**R3 发给秘书的图片是「说给秘书听」的。** 不管在 Telegram 还是网页：

- 图片先照常存成一份资料（原件要留着，能点开看），然后**马上**读图（R1），把读到的内容和用户写的文字一起作为这一句话交给秘书。秘书的回答和动作基于图片内容：发一张带日期的通知截图并说「帮我记一下」，应该建出带那个日期的待办。
- 没写文字只发图时，秘书也要回应：说出它看到了什么，能办的办掉，拿不准要做什么时问一句。不再只回「收到，已存进资料」。
- 读图失败或没有能看图的通道时，照旧存成资料，并明说「图片存好了，但我现在看不了图」，有文字就按文字办。
- 回执里有一条「存了一张图片」，可以撤销（撤销就是删掉这份资料）。
- 图片是这句话的一部分：后台整理这句话时，依据仍然只能是用户写的文字；图片里的内容只帮助理解，和 AI 的回复同等对待（见第 2 阶段第 2 批 R23 的做法）。

**R4 网页输入框能带图片和文件。** 首页和事项页的秘书输入框旁边有一个附件按钮，也可以直接粘贴或拖进来。支持的类型和大小跟「导入资料」一致（图片、PDF、音频，20 MB 以内）。选了之后在输入框上方显示一个可以去掉的小条，发送时一起发出。音频按现有的语音转写处理，PDF 存成资料并把读出的文字的开头交给秘书。

**R5 Telegram 和网页走同一条路。** 两边调用同一个后端入口，不各写一套。

## 不做的

- 不解析导入的聊天记录里的图片（见任务 U1 的决定）。
- 不做视频。
- 不改已有资料：已经用 tesseract 读过的图片不重读（要重读的话以后单独做）。

## 验收序列

| # | 操作 | 预期 |
|---|---|---|
| V1 | 假的看图模型返回「缴费通知：10 月 15 日前交物业费 800 元」；在网页带这张图说「帮我记一下」 | 秘书的模型收到的内容里有这段读图结果；建出待办；图片存成资料，能点开；回执里有「存了一张图片」 |
| V2 | 同 V1，只发图不写字 | 秘书有回应，内容来自读图结果；不是「收到，已存进资料」 |
| V3 | 在 Telegram 发同一张图加文字 | 和 V1 结果一致（同一个后端入口） |
| V4 | 没有能看图的通道 | 图片存成资料；回答里明说看不了图；有文字时按文字办事；后台用 tesseract 读出文字 |
| V5 | 看图调用失败（模型返回 500） | 同 V4；失败的调用不记花费 |
| V6 | 后台处理一张单独导入的图片 | 资料的文字来自看图模型，表示方式是 `vision`；花费记录里有一行 `vision` |
| V7 | 撤销「存了一张图片」 | 这份资料被删掉；这句话的其他动作不受影响 |
| V8 | 带图说一句话，后台整理这句话；假的整理模型把图片里的字当依据 | 这一项被丢掉；用用户写的文字当依据的照常保留 |
| V9 | 网页：点附件按钮选图、粘贴一张图、拖一张图 | 三种都出现小条，可以去掉；发送后输入框清空；超过 20 MB 或类型不支持时在输入框旁边说明原因，不发送 |
| V10 | 每个支持看图的通道协议各一次请求 | 请求体里图片的写法符合该协议；Codex 通道不支持时返回明确的错误 |
