# PCAS Historical Records

This catalog records earlier tasks, research, evaluations, and deployment results.
The [Documentation Index](../README.md#complete-document-catalog) lists every document by category.
Current specifications are separate from this history.

## How to Read a Record

A phase contract describes the behavior and assignments for that phase.
Later changes can replace its rules. Its precedence statement does not override the current whitepaper.
An evaluation proves only its recorded data, channel, date, and scope.
A research proposal is not an implementation decision.
An old assigned task is not a current instruction to resume work.

Old task and research bodies remain in their original locations.
This preserves source references and links between acceptance records.
The former primary specifications remain available in Git history at commit `c9ac3fd`.
